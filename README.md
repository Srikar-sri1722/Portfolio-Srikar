# Kandula Srikar | Portfolio

🔗 **Live Site:** [portfolio-srikar.onrender.com](https://portfolio-srikar.onrender.com/)

Personal portfolio of **Kandula Srikar** — B.Tech CSE (AI & Data Science) student at Vishnu Institute of Technology, Bhimavaram. Showcases autonomous multi-agent AI projects, Power BI analytics dashboards, and live-tracked coding stats.

## Features
- **AI Agent Sandbox** — interactive simulator for a multi-agent (Search → Reader → Writer → Critic) research pipeline
- **AI Assistant Chatbot** — answers visitor questions about education, skills, and projects
- **Live Coding Dashboard** — LeetCode / GeeksforGeeks / GitHub stats with charts
- **Power BI Analytics Preview** — interactive sales dashboard demo
- **Command Palette** (Ctrl+K) — quick navigation across the site
- **Contact Form** — direct messages delivered via Formspree

## Tech Stack
- HTML5, CSS3, vanilla JavaScript
- [Chart.js](https://www.chartjs.org/) for data visualizations
- [Lucide Icons](https://lucide.dev/)
- [Formspree](https://formspree.io/) for contact form email delivery
- Hosted on [Render](https://render.com/) (static site)
